# 麻糬 desktop pet

住在工作列上的桌面寵物。右鍵 →「換角色」切換：

- **麻糬**：麻糬貓，愛吃飯糰
- **魔人普烏**：愛吃糖果。有兩個型態
  - 第一型態（胖普烏）：連點 5 下會把牠惹毛 → 噴蒸氣變身
  - 第二型態（超級普烏）：走得快、一直冒蒸氣、講話很嗆；餵糖果會冷靜下來變回胖普烏

共通玩法：

- 左鍵點：開心跳一跳
- 拖曳：抓起來晃，放手會掉下來
- 右鍵（或系統匣圖示）：餵食、摸頭、變身、跟著滑鼠走、睡覺、換角色、叫回螢幕中間、結束
- 放著不管會自己散步，久了會睡著；會慢慢肚子餓

所有角色都是用程式碼（GDI+）畫的，沒有任何圖片素材。魔人普烏為《七龍珠》角色的 Q 版同人二創，角色版權屬原作者鳥山明／集英社／東映動畫。

## 編譯

不需要安裝 SDK，用 Windows 內建的 .NET Framework 4.x C# 編譯器：

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
.\bin\DesktopPet.exe
```
